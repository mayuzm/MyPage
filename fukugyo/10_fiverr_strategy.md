# Fiverr 方針の見直し（2026-11-07 v3：Gigを2本に分ける）

## 結論
**Gigを2本に分ける。Gig 1は日本全体の行程を公式情報で確かめて作り直す入口、Gig 2は北海道・離島・自然に特化して一から作る高単価。**
- Gig 1（先に出す）：お客様（またはAI）が作った日本の行程を、1日ずつ公式の時刻表・運行情報で確かめ、時刻の裏付けつきの行程表に作り直して納品する。地域は絞らない（差別化は「日本語の公式情報で裏を取る」ことで、全国で成り立つ）。出品文は `07_fiverr_gig.md`
- Gig 2（Gig 1の公開2〜3週間後、レビューの有無にかかわらず）：北海道・離島・自然の行程を一から作る。$90〜260程度。春の旅行の計画シーズン（12〜2月）に間に合わせるため、レビューは待たない
- 1本に両方を入れると何の専門家かがぼやけるため分ける（2026-11-07 ユーザーと合意）
- 旧Gig 3つは一時停止のまま。主力は新しいGigとして出す（旧Gigは表示もレビューもなく、引き継ぐものがないため）

## 調べてわかったこと（※印は仮説。公開後の数字で確かめる）
| 観点 | 事実 | 意味すること |
|---|---|---|
| Fiverrの競合 | 「japan itinerary」上位は日本人の経験者。Ayumi（元JNTO、100件）$75〜210、Tess（60件）$70〜245、Hiroko（14件）$80〜285。売り文句はどこも「personalized・local・hidden gems」 | 「日本人・現地目線」は差にならない。上位は全員「一から作る」で競っている |
| 北海道 | 北海道に特化して実績のあるGigはない（$5〜25で0件のみ） | ※空白か、探す人がいないだけかは未確認。だからタイトルは「Japan」で入口を広く取り、北海道は売りとして添える |
| 確かめる需要 | Tessの最安プランが「行程の添削 $70」。Fiverr外では添削だけで$199〜400の例あり | ※売れている数は不明。ただ「作る」と別の商品として成り立っている |
| AIの弱点 | AIの行程は乗り換え時間や営業時間を誤りやすい。地方では特にずれる（山形の夜の到着、宮島のロープウェイ営業時間の例） | AIで作る人が増えるほど、裏付けの価値が上がる |
| 地方の交通 | ローカルバスは本数が少なく、時刻表・案内は日本語のみが多い。Googleマップに載らない路線もある。JR北海道の特急は2026年3月から全席指定、道東の高速バスは冬だけの路線あり、運転手不足で減便 | 日本語で一次情報を読めることが、そのまま価値になる |
| 北海道の需要 | 2025年の外国人延べ宿泊数は1,330万人泊（前年比+29%、2019年比+51%） | 市場は伸びている |
| 時期 | 春（桜）の旅行は12〜2月に計画される。ただしJRは毎年3月中旬にダイヤ改正があり、12〜2月には新しい時刻表が出ていないことが多い | 12月上旬までに公開。納品物に「現時点の時刻表で確認」と明記する |

## SWOT
| | プラス | マイナス |
|---|---|---|
| 内部 | **強み**：時刻表レベルまで詰める細かさ／日本語の一次情報を読める／北海道・屋久島など地方を回った経験と写真／PMとして要望を1つの計画にまとめる力／英語力 | **弱み**：レビュー0件／平日の日中は返信できない／使える時間は平日夜30分と週末だけ／宿や飲食店を名指しで勧められない |
| 外部 | **機会**：AIで行程を作る人の増加／北海道の外国人宿泊の急増／地方の交通の変化（全席指定・減便・季節運行）／12〜2月の春旅行の計画シーズン | **脅威**：AIの精度向上／$5〜35の安い出品が多い／Fiverrは返信が速い人や上位出品者を優先しやすい／3月のダイヤ改正で時刻が変わる |

掛け合わせると：
- **強み×機会**：AIの行程が増えるほど、日本語で裏を取れる人の価値が上がる。AIは敵ではなく集客の入口
- **弱み×機会**：お客様がすでに宿や便を決めているので、「名指しで勧めない」制約がほぼ問題にならない
- **強み×脅威**：上位の出品者とは「作る」で戦わず、「裏付け」で別の棚に並ぶ

## Gig 1の形（案）
タイトル案：I will review your Japan itinerary and catch what AI misses, using Japanese sources

納品物：お客様の行程をもとに作り直した行程表（PDF）。各区間に公式の時刻・所要時間を記載し、問題のある箇所（最後のバスに間に合わない、予約が必要な特急、冬は運休、移動時間が足りないなど）に印と理由をつける。直し方は「手段と時間帯の目安」までにとどめ、特定の便や宿を選んで勧める書き方はしない。

| | Basic | Standard | Premium |
|---|---|---|---|
| 範囲 | 5日まで | 10日まで | 14日まで |
| 中身 | 問題の指摘と直し方＋時刻つき行程表＋予約リスト | Basicと同じ（長い旅程向け） | Standard＋修正2回 |
| 納期 | 5日 | 7日 | 12日 |
| 開始価格 | $45 | $85 | $150 |
| レビュー5件後 | $60 | $110 | $190 |

## 1件あたりの手間と手取り（目安）
| | 作業時間 | 手取り（手数料20%後） | 時給 |
|---|---|---|---|
| Basic $45 | 約3時間 | $36 | 約$12 |
| Standard $85 | 約6時間 | $68 | 約$11 |
| Premium $150 | 約10時間 | $120 | 約$12 |

- 開始価格は時給$11〜12。レビュー5件後に上げると時給$15〜16、2本目の「一から作る」Gigでさらに上を狙う
- Tess（60件）の添削$70より下、新人の$10〜35よりは上。「安さ」ではなく見本の質で選ばれる位置にする
- 受付は1件ずつ。Premiumは土日2回分かかる

## 必ず書くこと
- 「行程表の作成・作り直しのサービス。予約・手配はしない」
- 「現時点で公表されている時刻表で確認。3月のダイヤ改正や運休があるため、出発前に再確認を」
