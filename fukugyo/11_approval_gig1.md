## 1. 3つのプランと価格（価格戦略の専門家役がレビュー）

| | Basic | Standard | Premium |
|---|---|---|---|
| 名前 | Short Trip Review | Full Trip Review | Long Trip Review |
| 対象 | 5日まで | 10日まで | 14日まで |
| 地元のおすすめ | 3か所 | 6か所 | 10か所 |
| 修正 | 1回 | 1回 | 2回 |
| 納期 | 7日 | 10日 | 14日 |
| 開始価格 | $45 | $85 | $130 |
| レビュー5件後 | $60 | $110 | $170 |

**前の案から変えたところ**
- **Premiumを$150から$130に下げた**：1日あたりの単価がStandardより高く見えていたため
- **納期を5/7/12日から7/10/14日に延ばした**：日曜の夜に注文が入っても、作業できる土日を必ず含むようにするため。Basicの7日は、Fiverrの「7日以内」の絞り込みにも入る
- **作業時間の見積もりを直した**：Basicは約4.5時間で、時給は約$8（Standardは約$9、Premiumは約$10）。最初は時給が低いことを前提に、レビュー5件で値上げする（値上げ後は時給$11〜13）
- **追加料金のオプションは付けない**：15日以上の旅行はメッセージで相談してもらい、個別に見積もる

**プランの説明（日本語訳）**
- Basic：5日まで。時刻表と飲食店の確認、おすすめ3か所、予約リスト、PDF、修正1回
- Standard：10日まで。Basicの内容を、長い旅行や複数の地域を回る旅行向けに。おすすめ6か所、修正1回
- Premium：14日まで。Standardの内容を長い旅行向けに。おすすめ10か所、修正2回

## 2. よくある質問（コピーライター役がレビュー）

| 質問 | 答えの要点 |
|---|---|
| 行程はどんな形式で送ればいい？ | 何でも大丈夫です（メモ、表、スクリーンショット、AIの行程）。Fiverrに貼るか添付してください |
| **全部作り直されるの？**（新しく追加） | いいえ。うまくいくところは残し、直すところだけ理由を添えて変えます。良い計画ならそうお伝えし、その分の時間をおすすめ探しに使います |
| ホテルや電車を予約・指定してくれる？ | いいえ。予約も電話もせず、ホテル・電車・ツアーも選びません。合わない部分は「どんな手段で、何時ごろ」までお伝えします |
| レンタカーのルートも見てくれる？ | はい。運転時間、季節の通行止め、暗くなってからの運転がないかを確認します |
| 時刻はいつ時点のもの？ | 納品時点の時刻表です。3月のダイヤ改正などがあるので、出発の1週間前に再確認してください |
| 飲食店はいくつ確認するの？ | 1日2軒まで（昼と夜）。日本の口コミ、定休日、支払い方法を確認し、近くに明らかに良い店があれば提案します |
| 修正の範囲は？ | Basic・Standardは1回、Premiumは2回。同じ旅行の中での変更に限り、日付の変更や日数の追加は新しい注文になります |
| いつ頼めばいい？ | 旅行の3週間前までが目安です。それより急ぎならまずメッセージをください。**24時間以内に返信します**（主に昼休みと夜、日本時間） |
| まだ行程がないけど頼める？ | このサービスは、ある行程を確認するものです。行きたい場所の一覧しかない場合は、まずメッセージをください |

前の案から変えたところ：返信は「12時間以内」だと平日に守れないため、「24時間以内」にしました。「地方の行程で一番問題が見つかる」は実績がないのに言い切っていたので、削りました。

## 3. 購入後にお客様に聞く質問（5問。必須は4問）

1. 行程（貼り付けか添付。日ごとの計画ではなく行きたい場所の一覧なら、そう書いてもらう）
2. 旅行の日付、日本に着く・出る空港か都市、わかれば飛行機の時刻
3. 移動手段（レールパス、レンタカー、バス）と、予約済みのもの（宿、電車、ツアー）。予約番号やパスポート情報は送らなくてよい
4. 誰と行くか（人数、子どもの年齢、長く歩けない人）、好きなこと（食・自然・歴史・買い物など）、苦手な食べ物。おすすめ選びに使う
5. （任意）この計画で不安なこと、そのほか伝えておきたいこと

## 4. プロフィール（日本語訳）

> こんにちは、Yuiです。Wander Japanは、ここでの私の旅行サービスの名前です。東京近郊に住む日本人で、AIで作ったものも含め、日本旅行の行程を日本の時刻表と、地元の人が実際に使う口コミサイトで確認しています。本業ではWebのプロジェクトを管理していて、あいまいな計画をわかりやすく、実行できる形にするのが仕事です。自分の旅行も、屋久島から道東まで、同じやり方で一つひとつの移動時間まで詰めて計画しています。カナダで学び、働いた経験があるので、初めての国で迷う気持ちがわかります。返信は日本時間の昼休みと夜にしています。

確認してほしいこと：「カナダで学び、働いた」が実際の経験と合っているか。プロフィール写真は、「Yui」という名前と印象が合うものにする。

## 5. 英語の見本（交通の専門家役が事実確認）

ファイル：`04_sample_itinerary/review_sample_en.pdf`（2ページ。画像は `review_sample_en_full.png`）
内容：AIで作った「京都→白川郷→高山」1月の2日間を見直した例。1ページ目は見つけた問題の一覧（変える4件、残す2件、足す3件）、2ページ目は直した1日目の時刻表と予約リスト。

事実確認で直した主な点：
- 「10:40 金沢発の白川郷行きバス」は12月以降のダイヤにないため、実在する11:10発（12:35ごろ着）に直した
- 「金沢〜白川郷のバスは全席予約制」は誤りで、一部の便だけが予約制。表現を直した
- 「敦賀は同じホームで乗り換え」は誤り。新幹線と特急は階が違うので、「10〜15分みておく」とした
- 宮川朝市は冬は8時から（「7〜8時」から直した）。白川郷のライトアップは1〜2月
- 飲食店は特定されないよう、「行程にあった有名店」「近くの小さな焼肉店」とぼかした
- 出品文の「最終バスが16時30分」も、実際の路線とずれるため「最終バスが早い」にぼかした（説明文は1,168字）

## 6. ギャラリー画像3枚（デザイナー役がレビュー：3.3/5 → 指摘をすべて反映）

ファイル：`05_thumbnails/fv2_main.png`、`fv2_sample.png`、`fv2_how.png`（元データ `fiverr_gig1.html`）
- 1枚目：「JAPAN ITINERARY CHECK / I catch what AI misses / Checked with Japanese timetables and local reviews」（日本旅行の行程チェック／AIが見落とすところを、私が見つけます／日本の時刻表と地元の口コミで確認）＋富士山と五重塔の写真
- 2枚目：「Every change, explained」（すべての変更に理由つき）＋見本の表を拡大＋3本の引き出し線（日本語の出典／日本の口コミサイトで飲食店を確認／残す・変える・足すを1日ずつ）
- 3枚目：「Send your plan. Get back one that works.」（計画を送れば、ちゃんと回れる計画が戻ってきます）＋流れ3行＋北海道の直線道路の写真

レビューで直したところ：
- 1枚目は検索結果の小さい表示（横約300px）だと、日本のサービスだとわからなかった。「JAPAN ITINERARY CHECK」を足し、写真も道路から五重塔に替えた。観光客が写らない範囲で切り抜いている
- 見出しは「Catch what AI misses」から「I catch what AI misses」に変え、誰が見つけるのかをはっきりさせた
- 2枚目は見本の文字が小さすぎて読めなかった。表の4行だけに絞って拡大し、引き出し線を該当箇所に合わせた
- 3枚目は回転寿司の皿の朱色が「赤を使わない」ルールに近く、流れとの結びつきも弱かった。道路の写真に替えた
- 見出しのフォントを、丸みの強いNunitoから、少し硬めのDM Sansに変えた（テンプレート感を減らすため）
