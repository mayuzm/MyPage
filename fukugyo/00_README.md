## 決めた方針（レビューを経て変えたところ）
- **売り**は「幹事さんの手間が減る」だけでなく、「予算や苦手なことなど、言い出しにくい本音を名前を出さずに集められる」こと
- **価格**：ココナラは先着3件2,500円 → 3,500円 → レビュー5件で4,500円。Fiverrは $20 / $45 / $85 から始め、レビュー5件で $30 / $65 / $120
- **受付枠は1件、納期は10日**（平日夜30分＋土日で無理なく回すため）
- **法律に関わる書き方**を全ファイルで統一：「行程表（資料）の作成。予約・手配・代理、特定の宿や便を選んでお勧めすることはしない。電車・バスは、お客様が決めた便の時刻を公式時刻表から記載する」

## 公開前にあなたにしかできない確認・準備
1. **「旅程デザイナーYui」名義のGoogleアカウントを作る**：Googleフォームやドキュメントを共有すると持ち主の名前が表示されるため、本名やGmailを見せないようにします
2. **見本の移動時間を地図アプリで測り直す**：「西明石→淡路ハイウェイオアシス 約1時間〜1時間15分」は、レビューで「通常は30分前後では」と指摘されました。鳴門→明石の「約2時間10分」もあわせて確認し、違っていれば教えてください（見本を直します）
3. **出品画面で確認すること**
   - タイトルが24文字で通るか（通らなければ、23文字の代わりの案を使う）
   - お届け日数を「購入日から数える」のか
   - 自動承諾までの日数（メッセージテンプレート7の期限に使う）
4. **法律の線引きに不安があれば**：ココナラのガイドラインを読み、必要なら都道府県の旅行業の担当窓口に問い合わせる（サブエージェントも「断言はできない」としています）
5. **Fiverrの古いGigを一時停止する**
